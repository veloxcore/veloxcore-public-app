FAQ

Common questions.

Questions we get on almost every discovery call — answered honestly.

Do you migrate existing pipelines, or only build from scratch?
Both. Most clients come with an existing Hadoop or SSIS estate that needs modernising. We do a full discovery first to catalogue what exists, what to keep, what to replace, and what to retire — then migrate in phases so nothing breaks in production.
How do you handle schema evolution without breaking downstream consumers?
We set up an Avro schema registry at the Event Hubs producer level and implement contract tests in the CI pipeline of every upstream team. Breaking changes are caught in PR review, not at 11 PM on a Saturday. We also version events and maintain backward compatibility windows.
What SLA do you offer on managed pipelines?
Our standard managed SLA is 99.9% monthly uptime with a 4-hour response time for P1 incidents. For enterprise clients on dedicated infrastructure we can offer 99.97% with 1-hour P1 response. All SLAs are contractual — not marketing language.
How long does a typical data engineering engagement take?
Discovery and design take 2–3 weeks. A mid-complexity pipeline build (single data source, 3–5 downstream consumers) typically takes 6–8 weeks. A full data platform rebuild with multiple sources, ML integration, and Power BI delivery is usually 14–20 weeks.
Do we need to be on Azure already?
No. We can set up an Azure environment from scratch and migrate on-premises or multi-cloud workloads to it. We're also happy to work alongside an existing Azure estate — the discovery phase tells us exactly what the starting point is.
