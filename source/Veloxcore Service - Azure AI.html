FAQ

Common questions.

Questions we get on almost every Azure discovery call.

How do you handle zero-downtime cutovers?
We run source and target environments in parallel until the target has proven parity in a validation window — typically 1–2 weeks. Traffic shifts are done via Azure Front Door weighted routing, starting at 1% and increasing gradually. At no point do we do a hard cutover without a validated rollback plan.
What does Azure OpenAI production actually require?
Beyond the API key: private endpoint deployment, content filtering configuration, system prompt versioning, token budget alerts, fallback model routing, request logging with PII redaction, and an evaluation harness to catch prompt drift. Most "production" Azure OpenAI setups we've inherited were missing at least four of these.
We're already on Azure — can you help modernise without a full migration?
Yes. Most of our Azure engagements are modernisation, not migration. We assess your existing estate against the CAF and identify the highest-value improvements — landing zone gaps, security posture issues, cost optimisation, and AI-readiness gaps — then prioritise them into a phased roadmap.
Does Microsoft Gold Partner status actually matter?
For enterprise Azure work, yes. It gives us early access to new services (we were in the Azure AI Foundry preview before GA), a direct escalation path to Microsoft engineering for support cases, and co-sell motion if you need Microsoft account involvement in procurement.
